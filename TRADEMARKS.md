# CineBraid trademarks and brand assets

The CineBraid **code** is licensed under the Apache License 2.0. That licence
deliberately does not grant trademark rights — see section 6 of [LICENSE](LICENSE),
"Trademarks". This file says what the separate name and logo terms are, so that
neither has to be bolted onto the licence.

**Code rights and trademark rights are separate.** Nothing here restricts what
Apache 2.0 lets you do with the source: you may use, modify, distribute and build
products on CineBraid, commercially or not. What this file limits is the use of
the identity that tells a user which project they are looking at.

## What is covered

"CineBraid", the CineBraid wordmark and the CineBraid logo are branding of
Frombach Studios. In this repository that includes, and is not limited to:

- `public/cinebraid-mark.svg` — the application mark, used as the browser icon.
- `public/cinebraid-logo-xs.png` — the CineBraid logo used in the application shell.

These two files are shipped so that an unmodified CineBraid identifies itself
correctly. They are **not** placed under Apache 2.0, and the licence in `LICENSE`
should not be read as a grant to use them as your own branding. Every other
tracked asset in this repository is covered by the repository licence.

## What you may do without asking

- Use the name **CineBraid** to refer accurately to this project — in
  documentation, articles, comparisons, talks, issues, package descriptions and
  the like. Nominative reference is fine.
- Say truthfully that your work is *based on*, *built with*, *compatible with* or
  *a fork of* CineBraid.
- Run, modify and self-host CineBraid, including with the logo intact, as long as
  it is still recognisably CineBraid and you are not passing your build off as an
  official one.

## What you may not do without written permission

- Use the CineBraid name or logo as the name, logo or primary branding of a
  **different** product, distribution, service or company.
- Use the name or logo in a way that suggests your fork, build or service is
  official, endorsed, certified, supported or maintained by Frombach Studios when
  it is not.
- Register the CineBraid name, the logo, or anything confusingly similar, as a
  trademark or a domain that implies it is the official project.
- Modify the logo and continue to present the result as the CineBraid logo.

## If you fork

Forks are welcome; Apache 2.0 grants you that. If you distribute a modified
CineBraid to other people, please make it obvious that it is yours and not ours:
give it its own name and your own mark, and remove or replace
`public/cinebraid-mark.svg` and `public/cinebraid-logo-xs.png`. Keeping the
copyright and licence notices required by Apache 2.0 section 4 is a separate
obligation and still applies.

A short, honest line — "*a fork of CineBraid, not affiliated with Frombach
Studios*" — is exactly the kind of use this policy is written to permit.

## Questions

If you want to use the name or logo in a way this file does not clearly allow,
ask first through the repository rather than assuming. A permission that is not
in writing has not been granted.
