# Install CineBraid v6.6.4-studio.repair.2

1. Stop CineBraid.
2. Back up the current application folder and project folder.
3. Extract the repair.2 patch over v6.6.4-studio.repair.1, preserving folders and replacing files.
4. Restart CineBraid.
5. Hard-refresh the browser once.

The patch does not include `data/config.json`, so local provider keys and model settings remain untouched.
