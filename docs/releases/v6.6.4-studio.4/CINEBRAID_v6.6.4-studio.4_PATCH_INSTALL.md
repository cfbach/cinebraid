# Install — CineBraid v6.6.4-studio.4

## Recommended
Use the complete ready-to-run archive for the cleanest installation.

## Patch installation
The patch is intended for `v6.6.4-studio.3`.

1. Stop CineBraid.
2. Back up your current install and project folders.
3. Extract the patch over the `studio.3` application folder, preserving paths.
4. Start CineBraid.
5. Open **Settings → Files & storage** and choose **Check active paths**.
6. Apply storage settings only after confirming the displayed paths.

Changing the project root causes CineBraid to copy missing project data into the new root before activating it. Existing files in the destination are not overwritten.
