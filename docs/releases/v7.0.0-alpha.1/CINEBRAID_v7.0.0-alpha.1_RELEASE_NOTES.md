# CineBraid 7.0 Public Alpha — source freeze notes

Version: `7.0.0-alpha.1`; intended tag identity: `v7.0.0-alpha.1`.
This prepares a source/package candidate, not an assertion of an existing GitHub
Release, tag or download. Exact source/tree and artifact hashes are established
by reviewed freeze receipts and the subsequent B6B manifest.

## Working now

Trustworthy core desktop production: Project Bible → exact reference/state/view
→ Shot Desk → deterministic Build/exact request review → imported/returned
candidate → Results/Screening → deliberate human decision → reopen.
Single-sidebar scene/shot navigation and direct stage clicks keep work reachable.
Editorial shots and canonical planned duration do not require generation.

Qualified request targets: GPT Image 2 via fal (T2I, blocking, edit,
multi-reference, explicit inpaint mapping); MiniMax H3 via fal (FL2VA T2V/I2V/
first-last; Ref2VA explicitly selected R2V). Exact model/provider/mode controls
apply; catalogue entries are not automatically supported.

Native repair separates an unapproved canvas from current approved appearance
references and durable non-authority technical guides/base-bound masks. Request
review/freshness and human decisions remain authoritative. Media Inspector reads
the exact linked job's submitted prompt without duplicate provenance storage.

Imported/recorded audio can be reviewed, approved and placed with role/timing.
Established current-code qualification covers media/authority/provenance reopen,
physical handoff and separate-root backup/restore. Final-package checks follow separately.

## Known limitations / experimental

Desktop-first with basic responsive behavior; dedicated mobile polish deferred.
Manual physical media handoff/records, no built-in NLE/export pipeline or automatic
sound mix. Source packages require Node/npm and `npm ci`.

Deterministic model-specific Build remains trusted. Braidy is optional/advisory/
experimental, with configurable OpenAI target review and mandatory coverage/
omission inspection. Even stronger models lose intent; no assistant is automatically
task-qualified. Assisted continuity repair and per-frame AI critique remain unqualified.
Other optional services require workflow/model-specific evaluation.

Generated images/video can drift, including beyond masks; dispatch is not artistic
approval. External services send selected inputs and can incur cost. Local config/
credentials are server-side plaintext under OS permissions, not an encrypted vault.
Keep backups private; never publish secrets.

## Coming next / 7.x

Real-production refinement, inherited production libraries, start from existing
production, DF-04/05/06 follow-ups, model benchmarking/recommendations, broader
qualified provider/model coverage and workflow polish. Plans, not shipped capabilities.

## Longer-term direction

Shared/series production systems, richer export/handoff, deeper local AI and
collaborative/automated production workflows. Direction, not commitments.
