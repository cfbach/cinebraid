# CineBraid v6.6.3.5 handoff

## Current focus

Blocking generation and automation are now discoverable from Shot → Look & blocking.

## User paths

- Manual blocking: Upload a blocking image and choose Use as guide.
- Manual assisted generation: Build Prompt, then Generate from the prompt result.
- Durable blocking-only automation: Automate Blocking, confirm rounds/output cap, and let CineBraid build, generate, review, retry, and select a guide.
- Finished still automation remains under Frames.

## Next step

Use v6.6.3.5 in the external test. Avoid another broad hardening release without feedback from real users.
