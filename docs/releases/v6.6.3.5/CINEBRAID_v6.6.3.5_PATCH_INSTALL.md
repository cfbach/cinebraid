# CineBraid v6.6.3.5 patch installation

1. Stop CineBraid.
2. Back up the current application folder and project data.
3. Extract the patch over v6.6.3.4, preserving the folder structure.
4. Start locally with `npm start`, or on the Spark for desktop access with `npm run start:lan`.
5. Hard-refresh the browser once.

The patch does not migrate project data.
