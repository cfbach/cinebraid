# Install — CineBraid v6.6.4-studio.repair.11

## Patch from repair.10
1. Stop CineBraid.
2. Back up the current application folder.
3. Extract `CINEBRAID_v6.6.4-studio.repair.11_patch-from-v6.6.4-studio.repair.10.zip` over the repair.10 folder.
4. Replace included files when prompted.
5. Restart CineBraid.
6. Hard-refresh the browser once so the repair.11 cache-busted assets load.

The patch does not replace project folders, media, `data/config.json`, API keys, local-model configuration, or `node_modules`.

## Full install
Extract `CINEBRAID_v6.6.4-studio.repair.11-ready-to-run.zip` and start it normally.
