# CineBraid v6.6.3.3 patch installation

## Patch from v6.6.3.2

1. Stop CineBraid.
2. Back up the existing CineBraid folder and project data.
3. Extract `CINEBRAID_v6.6.3.3_patch-from-v6.6.3.2.zip` over the v6.6.3.2 application folder.
4. Preserve your existing `data/` and `projects/` folders when prompted.
5. Start CineBraid normally, or use `npm run start:lan` when accessing the Spark from another device.
6. Hard-refresh the browser once so the v6.6.3.3 cache-busted scripts load.

No project migration is required.
