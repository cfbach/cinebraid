# Install — CineBraid v6.6.4-studio.repair.5

## Patch from v6.6.4-studio.repair.4
1. Stop CineBraid.
2. Back up the current CineBraid application folder and project folder.
3. Extract `CINEBRAID_v6.6.4-studio.repair.5_patch-from-v6.6.4-studio.repair.4.zip` over the repair.4 application folder.
4. Preserve the archive’s folder structure and replace matching application files.
5. Restart CineBraid.
6. Hard-refresh the browser once so the repair.5 cache-busted assets load.

The patch does not contain `data/config.json` or project media.

## Complete install
Extract `CINEBRAID_v6.6.4-studio.repair.5-ready-to-run.zip` into a new folder and use the included setup/start scripts normally.

## Using MiniMax H3
1. Open **Settings → Generation**.
2. Enable FAL generation and confirm the FAL key is configured.
3. Open a shot and choose **Motion**.
4. Choose a MiniMax H3 workflow.
5. For multi-frame prompting, approve two or more shot frames and select **MiniMax H3 — Multi-Frame / Reference Video**.
6. Choose and order the active frames, describe each beat, add transition direction, then build the prompt.
7. Review the compiled H3 prompt and submit the paid generation.
