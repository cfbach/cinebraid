# CineBraid v6.6.4.0 — Shot & Scene Automation Restoration

## Summary

This release restores assisted still-production workflows as explicit, coherent options without weakening the manual-first workspace.

## Shot workflow

- Existing blocking attempts can be reviewed together by the vision assistant.
- CineBraid records per-attempt scores and recommends the strongest passing composition guide.
- A recommended guide can be installed before further paid generation.
- **Automate Blocking** remains a bounded blocking-only path.
- **Automate Full Shot** runs approved references → blocking review/generation → required-frame generation and review → approval.
- Existing approved blocking and frame work is reused before spending credits.
- Full-shot automation can optionally run scene continuity review after the shot finishes.
- Motion/video generation remains separate and manual unless deliberately opened.

## Scene continuity

- The shot workspace links directly to scene continuity and scene automation.
- Scene review compares approved shot stills with the Project Bible and approved character, location, prop, and vehicle authority images.
- Whole-scene automation can continue unfinished shots, review the assembled sequence, and run bounded correction cycles.

## Manual-first behavior

Manual projects still lead with upload, selection, human approval, and delivery. All new automation remains inside optional assisted disclosures. Default-visible shot controls remain capped at 10; the deliberate optional reachable ceiling is now 26 to expose Full Shot and Scene Automation entry points.

## Compatibility

No schema migration, provider change, or removal of existing project data is introduced.
