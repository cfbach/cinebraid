# Install CineBraid v6.6.4-studio.repair.1

1. Stop CineBraid.
2. Back up the current app folder and project folder.
3. Apply the patch over v6.6.4-studio.5, or use the complete ready-to-run package.
4. Preserve folder structure and replace included application files.
5. Restart CineBraid and hard-refresh the browser once.
6. Open Settings → Appearance and select **Dark studio** for the strongest contrast.
7. Test the Local AI connection after confirming the exact model name with `ollama list`.
