# Install — CineBraid v6.6.4-studio.repair.13

## Patch from repair.12

1. Stop CineBraid.
2. Back up the current application folder.
3. Extract `CINEBRAID_v6.6.4-studio.repair.13_patch-from-v6.6.4-studio.repair.12.zip` over the repair.12 application folder.
4. Replace files when prompted while preserving the folder structure.
5. Restart CineBraid and hard-refresh the browser once.

The patch excludes project media, `data/config.json`, API keys, provider settings, and `node_modules`.

## Complete install

Extract `CINEBRAID_v6.6.4-studio.repair.13-ready-to-run.zip` into a new folder and run normally.
